# RiftNote 0.2.0 — Pre-release

Windows x64向けの試用版です。まず少人数で操作とLeague Client連携を確認するための配布です。

## インストール

Assetsから **RiftNote-Setup-0.2.0-x64.exe** をダウンロードして起動してください。ソースコードのZIPは通常利用には不要です。必要に応じてSHA256SUMS.txtとダウンロードしたexeのSHA256を照合できます。

未署名のためWindowsの警告が表示される場合があります。セキュリティソフトを無効化しないでください。問題があれば画面の内容を知らせてください。

## 今回の改善

- 全メモ・Notebook・ビルド補足の横断検索と、該当箇所への移動
- Champ Selectで保存済み対策を優先表示
- 削除の取り消し、削除済み記事・メモの復元、自動バックアップ
- 未保存の下書きの復元、試合履歴の「記入済み」表示
- チャンピオン×レーンのビルド・ルーン雛形、メモの確認パッチ
- CD表示の補足、依存パッケージ更新とElectronのセキュリティ設定強化

## 試してほしいこと

1. 新規起動してメモを作成し、アプリを再起動しても残ること
2. 検索、削除の取り消し、バックアップの保存
3. League Client連携と、自分の試合履歴からメモを開けること

不具合はIssuesに、アプリのバージョン・Windowsのバージョン・再現手順・期待した動作を記載してください。個人DB、バックアップ、lockfileは添付しないでください。脆弱性はSecurityの非公開報告を使用してください。

## 制限

- クリーンなWindows環境でのインストール・更新・アンインストールは未検証です。
- 更新前はSettingsからバックアップを書き出してください。新しいDBを旧版へ戻す操作は保証しません。
- メモ・バックアップは端末内に平文保存されます。クラウド同期・自動アップデートはありません。
- カタログは16.18.1です。現行パッチと異なる可能性があります。CDは全形態・試合中の残り時間を再現するものではありません。
- 既知の依存脆弱性の監査は2026-10-12時点で0件ですが、脆弱性ゼロを保証するものではありません。
