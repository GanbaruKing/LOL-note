# RiftNote 0.2.1 — Pre-release

メモ編集の「確認パッチ」入力欄と、保存済みメモ上の確認パッチ表示を削除しました。既存の値はデータ互換性のため保持されます。DB・バックアップ形式の変更はありません。

Assetsの **RiftNote-Setup-0.2.1-x64.exe** をダウンロードしてください。更新前にSettingsからバックアップを書き出し、RiftNoteを終了してからインストーラーを実行してください。SHA256SUMS.txtも添付しています。

Windows x64向けの未署名の試用版です。クリーンなWindowsでのインストール・更新・アンインストールは未検証です。メモ・バックアップは端末内に平文保存されます。自動更新はありません。

型チェック・ビルド・Lint・関連E2E 5件で変更を確認しています。基本機能と試用手順は[0.2.0の案内](https://github.com/GanbaruKing/LOL-note/blob/main/docs/releases/0.2.0.md)、データの扱いは[SECURITY.md](https://github.com/GanbaruKing/LOL-note/blob/main/SECURITY.md)を参照してください。
