# RiftNote 0.2.0 改善機能

## 探す・読む

Searchは5種類の保存場所を統合します。Notebookの章/記事名、Champion名、本文、Roleをスペース区切りANDで検索し、かな・全角・大文字小文字の揺れを吸収します。結果は一致箇所付近の抜粋で表示し、ボタンで該当メモ/入力欄/記事へ移動します。PinのみにはNotebookのお気に入りも含みます。レーン指定時はレーンのない記事・共通対策・Champion Notesを含みません。

Champ Selectは敵を選ぶと、共通対策、対面メモ、ビルド/ルーン、Champion Notesを候補より先に表示します。選択を変更すると読み込み中に前の対面情報をクリアします。

Match Historyの記入済み表示は振り返りメモの正規のゲーム情報を参照します。複数メモがあればそれぞれ開けます。メモを削除/ゲーム情報を解除した場合は、履歴を再表示すると判定も変わります。

## 記録する

メモの確認パッチは任意で、16.18 / 16.18.1の形式です。保存・編集・検索・削除からの復元・バックアップで保持します。

ビルド/ルーンの「現在の内容を共通の雛形に保存」で自分のChampion×Roleの雛形を作成します。「共通の雛形からコピー」は確認後に編集中の内容を置き換えます。対面への確定は従来のページ保存です。雛形だけ保存しても対面は保存済みになりません。

## データを守る

- 対面/Championメモの削除は復元用領域へ退避してから実行します。削除直後の取り消し、またはSettingsで個別復元。復元時は新しいIDを使い、後から作ったメモを上書きしません。
- Notebookの記事の削除も保存処理と同じトランザクションで退避し、Notebookの削除済み記事一覧から個別復元できます。他の記事の編集を巻き戻しません。章だけの削除は従来どおり記事を未整理へ移します。
- `backups/auto-*.json`は起動時・5分ごと・正常終了時に変更がある場合だけ作成し、最新20世代を保持します。手動/復元前バックアップはローテーション対象外。全体の復元はSettingsの既存の確認付き復元から行います。
- 自動バックアップ失敗は画面に通知します。通常のDB保存は継続できます。同じPC内の保護なので、別端末/別ディスクへの保護にはJSONを別の場所に書き出してください。
- 下書きはChromiumの端末内ストレージに退避し、復元は明示的に選択します。正常保存/キャンセル/破棄後は対応する退避を削除します。閉じる確認では「下書きを残して閉じる」を選べます。下書きの保存失敗は表示します。JSONバックアップ・他PCへの移動対象には含みません。

## データ更新

`npm run data:update -- --version 16.18.1`で同梱パッチを再取得できます。version省略時は公式一覧の最新パッチを選びます。Champion・CD・アイテム/ルーン・ショップ分類を同じパッチで取得し、一時フォルダーで検証後に反映します。通信は限定回数再試行し、失敗時は元のカタログを変更しません。前のファイルは`.test-data/catalog-update-*/previous/`に保持します。

削除されたアイテムIDは旧ビルド参照用に保持し、ショップでは新規選択できません。ルーン系統/段/IDが既存保存形式と非互換なら更新を停止します。対応する移行を実装してから再実行してください。データ更新後はテスト・アプリ再ビルドが必要です。アプリ内の自動更新ではありません。レーン分類と手選定のカウンターメモはこの更新に含みません。

CDの注記はData Dragon 16.18.1のスキルIDと説明を確認したものです。Elise/Nidaleeはヒト形態、Jayceはハンマー形態、Corki Rは発射間隔、Zyra Wはチャージ、Yasuo Eは同一対象制限、Riven Qは再使用、Yone Wは攻撃速度依存、Zeri Qは通常攻撃扱いを区別します。別形態やチャージ補充時間の数値を推測して表示しません。

## 互換性・構成

DB v6→v7で両メモテーブルに確認パッチを追加。バックアップv4には雛形・削除済みメモ/記事を含みます。v1〜v3を引き続き読めます。旧形式には追加データがないので空として復元します。復元直前の自動退避は維持しています。

`ChampionPicker.tsx` / `SettingsPage.tsx`をAppから分離し、`drafts.ts`、`protection.ts`、`shared/search.ts`、`shared/cooldowns.ts`に共通処理を集約しています。

## 検証

- Repositoryの横断検索、かな/全角、条件併用、復元時のID衝突防止、雛形分離、v3互換性、記事の個別復元、自動バックアップ20世代と破損ファイル回復、CD例外を単体/統合テスト。
- Electronで検索から正しい対象を開く、削除取り消し、雛形コピー、メモとビルドの再起動復元、Notebook削除/保存失敗からの復元、疑似LCUで試合前参照と記入済み履歴を検証。
- 個人DB・旧個人ノート・個人Comfort Picksファイルにはアクセスせず、専用テストDBを使用。
